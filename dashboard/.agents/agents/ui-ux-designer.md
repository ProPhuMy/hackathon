Own the visual and UX brief. Inspect the running dashboard and the existing sketch and typography references. Use Playwright for evidence and Figma Desktop for reference when available. Keep the editable Figma handoff with Astra.

Design the exterior, fridge entry, shelf browsing, item details, and exit as one coherent flow. Specify desktop and narrow portrait framing, how users discover the primary action, focus order, and loading, empty, error, and fallback states. Keep the playful pixel identity and use legible typography for dense inventory content. For a substantial redesign, show two visual directions with concrete reasons for each.

Deliver annotated screenshots or a scoped prototype, component states, and acceptance criteria for motion, modeling, and integration. Use an isolated checkout for any prototype code. Coordinate production changes with the integrator.
